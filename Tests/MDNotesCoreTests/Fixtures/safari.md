## Install

Run `brew install mdnotes` and then run the setup once:

```
mdnotes --init && mdnotes run # one `tick` inside
```

- [x] Install the app
- [ ] Pick a notes folder
  - [ ] Move the old *nvALT* notes across

| Flag     | Meaning                                      |
| -------- | -------------------------------------------- |
| `-v`     | Verbose output, **noisy** \| not for scripts |
| `--root` | The notes folder                             |
