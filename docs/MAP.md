# MDNotes codebase map

Read this instead of exploring. One line per file: what it owns and its key names. Keep it
current: when you add, remove or move a file, fix its line in the same commit (CLAUDE.md).
Feature IDs like `S-2` refer to `docs/SPEC.md`; `ADR-000N` to `docs/adr/`.

## Sources/MDNotes (executable entry point)

- `Sources/MDNotes/main.swift` — imports MDNotesApp and calls `App.run()`. Nothing else lives here.

## Sources/MDNotesCore (pure logic: index, search, links, tags, file store; no AppKit)

- `Sources/MDNotesCore/NoteID.swift` — note identity as root-relative `/`-separated path incl. `.md`. `NoteID`, `.relativePath`, `.title`.
- `Sources/MDNotesCore/CaseFolding.swift` — the one case fold used by every case-insensitive comparison. `CaseFolding.fold`, `areEqual`.
- `Sources/MDNotesCore/WordSplitter.swift` — splits query text into whitespace-delimited words (S-2). `WordSplitter.words`, `foldedWords`.
- `Sources/MDNotesCore/BodySnippet.swift` — one-line list-row snippet from a body (S-6): every marker `MarkdownScanner` yields is dropped (headings, wikilink brackets, fences, emphasis, links, images, autolinks, list markers, blockquote prefixes, table pipes) and embeds, task boxes, separator rows and rules go whole; no syntax is read here (ADR-0019). `BodySnippet.make`, `maxCharacters`, `scanCharacters`.
- `Sources/MDNotesCore/LibraryScanner.swift` — walks the root for `.md` files, skipping `Trash`/`templates`; each folder listed with `getattrlistbulk` (names, kinds, dates in bulk, no `URL` or Objective-C per entry, I-11), dates rounded as `URL.resourceValues` rounds them. `ScannedNote`, `LibraryScanner.scan`, `noteID(forRelativePath:)`.
- `Sources/MDNotesCore/NoteStore.swift` — reads/writes one library root; iCloud availability and dataless detection (L-7/L-8). `NoteBody`, `NoteStore.read`, `url(for:)`, `requestDownload`, `isDownloaded`, `modificationDate(atExactly:)`.
- `Sources/MDNotesCore/AtomicWriter.swift` — temp-file-plus-rename writes so readers never see a mix (E-5). `AtomicWriter.write(_:to:)`, `Interruption` hook for tests.
- `Sources/MDNotesCore/OwnWrites.swift` — ledger of this process's own writes so the watcher ignores their echoes (E-6). `OwnWrites.record`, `contains`, `suppressing(_:store:)`.
- `Sources/MDNotesCore/FSEventsWatcher.swift` — FSEvents stream over the root, reporting changes as note ids (X-1), and image files that arrive, change or go by root-relative path in `LibraryChanges.images` (S-11, E-9, I-8), and templates that do by name in `LibraryChanges.templates`, `templates/` re-listed and diffed on a folder event (TP-7); a folder scan's report is not repeated by the note's own later event (X-2). `FSEventsWatcher.start/stop`, `Handler`, `WatchError`, `defaultLatency`, `knownNotes`, `knownTemplates`.
- `Sources/MDNotesCore/DownloadRequester.swift` — keeps a download request outstanding per evicted note, at most one per 60 s (L-9, ADR-0009). `DownloadRequester.requestDownloads`, `refreshOutstanding`, `Refresh`.
- `Sources/MDNotesCore/MarkdownScanner.swift` — single left-to-right pass yielding every ED-1 construct as flat tokens (no tree; nested ones are inner tokens, in location order, enclosing first): ATX and setext headings (ED-9), wikilinks, embeds, tags, inline and fenced code, emphasis (bold, italic, strikethrough by CommonMark flanking; underscores only at word boundaries), standard links and images, autolinks, bare http(s) URLs, list items (nesting by two spaces) and task boxes, blockquote prefixes, pipe-table rows and separators, thematic breaks after a blank line (ED-8). Each token carries `markers` and `content` ranges separately (ED-2). `paragraphRange` is the E-3 scope, covering both neighbours of an edited blank line. `MarkdownScanner.scan`, `Token` (`range`, `markers`, `content`), `Kind`, `Emphasis`, `paragraphRange`, `isTagCharacter`.
- `Sources/MDNotesCore/SearchIndex.swift` — immutable in-memory snapshot of all notes' searchable text (S-2/S-3/S-4, ADR-0003), each entry carrying its first embedded image's root-relative path (S-11). `SearchIndex`, `.Entry` (`firstImagePath`), `.Results`, `.Builder`, `query`, `queryTitles`.
- `Sources/MDNotesCore/SearchIndexBuild.swift` — builds snapshots from scanned notes, titles-only first for fast launch. `SearchIndex.build`, `titlesOnly`, `applying(reading:store:)`.
- `Sources/MDNotesCore/SearchIndexUpdate.swift` — applies watcher batches incrementally without a rescan (X-1); a changed image file re-resolves the notes whose embeds name it from the link index, no reread (S-11); a batch naming only templates leaves the index alone (TP-7). `LibraryChanges` (`images`, `templates`, `affectsIndex`), `SearchIndex.applying(changes:store:)`, `applying(imageChanges:images:)`.
- `Sources/MDNotesCore/NoteReferences.swift` — links and tags extracted from one body, feeding both indexes (K-1, T-1). `LinkTarget`, `NoteReferences(scanning:)`.
- `Sources/MDNotesCore/LinkIndex.swift` — outgoing targets, backlinks, and target-to-note resolution (K-2/K-5, ADR-0005). `LinkIndex.resolve`, `outgoing`, `backlinks`, `applying`, `Resolution`.
- `Sources/MDNotesCore/TagIndex.swift` — tags-to-notes and notes-to-tags, rebuilt incrementally with LinkIndex (T-2). `TagIndex.tags(in:)`, `notes(tagged:)`, `allTags`, `applying`.
- `Sources/MDNotesCore/LinkCompletion.swift` — rules for the `[[` popover: trigger, filter text, candidate titles (K-4). `LinkCompletion.anchor`, `filterText`, `titles`, `insertion`.
- `Sources/MDNotesCore/TagCompletion.swift` — same rules for the `#` popover (T-3). `TagCompletion.anchor`, `filterText`, `tags(withPrefix:in:)`, `insertion`.
- `Sources/MDNotesCore/NoteCreation.swift` — query text to note to create, or a typed rejection (C-2/C-3); `NoteStore.create` writes the file with a body, empty by default, never over an existing one (C-2, TP-4). `NoteCreation.noteID(forQuery:)`, `Rejection`, `NoteStore.create(_:body:)`.
- `Sources/MDNotesCore/NoteRename.swift` — edited title to renamed id or rejection, plus collision check (R-2). `NoteRename.noteID(renaming:toTitle:)`, `collision`, `NoteStore.rename`.
- `Sources/MDNotesCore/TemplateParser.swift` — template header block and `path` to `Template` or a typed rejection (TP-2); `{{date:FORMAT}}` (Unicode pattern via `DateFormatter`), `{{title}}`, `{{cursor}}` expansion with unknown tokens literal (TP-3). `TemplateParser.parse`, `expandPath`, `expandBody` (UTF-16 `cursorOffset`), `Template.pathNeedsTitle`, `Environment` (date, zone, locale for tests), `Rejection`.
- `Sources/MDNotesCore/TemplateStore.swift` — the `.md` files directly inside `templates/`, by name (TP-1): lists the folder as it is now, sorted case-insensitively, none when the folder is missing; reads one through `TemplateParser` (TP-2); which root-relative path is a template, for the watcher (TP-7). `TemplateStore.names`, `url(for:)`, `read`, `name(forRelativePath:)`, `folderName`, `directory`.
- `Sources/MDNotesCore/TemplateQuery.swift` — a search-field query in template mode (TP-5): first character `@`, the word attached to it as the name filter (S-2 substring, empty lists all), the remaining words joined by single spaces as the title. `TemplateQuery(_:)`, `filter`, `title`, `isTemplateMode`, `matches`, `names(matching:)`.
- `Sources/MDNotesCore/TemplateInstantiation.swift` — a template plus a title to the note it names and the body it gets (TP-4): expands the path (TP-3), judges it by the C-3 rules through `NoteCreation`, expands the body; `NoteStore.instantiate` opens an existing `<path>.md` untouched or creates it with folders and the body, the caret at `{{cursor}}` or the end. `TemplateInstantiation.plan`, `Plan`, `Rejection` (`.template`, `.path`; `message`, `LocalizedError`), `Outcome` (`created`, `cursorOffset`), `NoteStore.instantiate`.
- `Sources/MDNotesCore/LinkRewrite.swift` — pure plan for rewriting wikilinks after a rename (R-3). `LinkRewrite.plan`, `rewriting(_:replacing:)`, `Replacements`.
- `Sources/MDNotesCore/HTMLToMarkdown.swift` — markdown from pasteboard HTML (ED-13, ADR-0019): the HTML tidied and parsed by `XMLDocument(.documentTidyHTML)` (a UTF-8 byte-order mark prepended so tidy reads UTF-8), the tree walked once by a lazy writer (pending line breaks, spaces and opening emphasis markers land only when content follows; blockquote `> ` and list `  ` prefixes are a stack) emitting ATX headings, `**`/`*`/`~~` from tags or inline `font-weight`/`font-style`/`text-decoration` styles (Google Docs), `[text](href)` or `<href>`, `- `/`<n>. ` items nested by two spaces with `[ ]`/`[x]` from a leading checkbox, tight items, code spans and fenced blocks with the `language-` info string, pipe tables padded with the first row as header, `![alt](src)` for http(s) images only, `---`, paragraphs (`<p>`, a blank line) and lines (`<div>`, `<br>`; two breaks a blank line); everything else text only, scripts/styles/head nothing. `HTMLToMarkdown.markdown(fromHTML:)` (nil when unparsable).
- `Sources/MDNotesCore/ImageStore.swift` — where pasted/dropped images go under `i/`, which file an embed names (I-1, I-2), and a body's first embed that resolves to an existing image file (S-11). `ImageStore.write`, `url(forEmbed:)`, `relativePath(forEmbed:)`, `candidatePaths(forEmbed:)`, `firstImage(in:)`, `isImageFile`, `fileName`, `Failure`.

- `Sources/MDNotesApp/NoteListController.swift` — table data source/delegate over one `SearchIndex.Results`; inline title editing; date refresh on `NSCalendarDayChanged` and key window (S-6, S-9); row thumbnails looked up in `thumbnails` under `imageRoot` as rows are made, requested when not cached (S-11, PF-8), and asked for again when the image file changes on disk (X-1); template mode shows `TemplateRow`s (name, expanded path) instead of notes, selectable but never a note selection (TP-5). `NoteListController.show`, `show(templates:)`, `TemplateRow`, `templateRows`, `isShowingTemplates`, `selectedTemplate`, `select`, `beginEditingTitle`, `dateText`, `refreshDates`, `now`, `thumbnails`, `imageRoot`, `thumbnailPixelSize`, `thumbnailURL(for:)`, `imagesDidChange`.

`setNeedsDisplay(_:avoidAdditionalLayout:)` widens every redraw to the view's width so the margins move with their lines; intercepts Cmd-click and Cmd-Return for link opening (K-3); while Command is held over a link (found through `linkRange`, installed by the window controller, from its own tracking area's mouse moves and `flagsChanged`, the latter reading the pointer from `pointerLocationInWindow` or the window's `mouseLocationOutsideOfEventStream` since a modifier event's location is not the pointer's) shows the pointing hand, re-set after `NSTextView`'s own `mouseMoved` puts the I-beam back on every move, and a solid underline as a temporary attribute of the layout manager, never in the storage, and restores the I-beam when Command goes, the pointer leaves the link or the view (ED-12); copy, cut and drag write the file's text when attachments are on show (E-9); `paste(_:)` reads `pasteboard` in ED-13's order (an image to `onInsertImage` (I-1), else HTML through `HTMLToMarkdown`, else RTF through `RTFToMarkdown`, a conversion that is nil or empty falling through, else the plain string, else `NSTextView`'s own paste) and `pasteAsPlainText(_:)` (Paste and Match Style, Cmd-Shift-V, ED-14) the image or the plain string only; both insert through `insertText(_:replacementRange:)` so a paste is one undoable, styled, autosaved edit; `validateUserInterfaceItem` enables Paste for an image, HTML, RTF or a string and Paste and Match Style for an image or a string, reading no data. `EditorTextView(frame:layoutManager:)`, `editorLayoutManager`, `characterIndex`, `writeSelection(to:types:)`, `pasteboard`, `linkRange`, `pointerLocationInWindow`, `hoveredLinkRange`, `hoverUnderline`.
- `Sources/MDNotesApp/EditorLayoutManager.swift` — the editor's `NSLayoutManager` (ED-8, ED-10, ADR-0019), non-contiguous layout: `drawRuleExtensions` paints, for the glyphs the text view asks for (the visible rect), faded hyphens in quaternary label colour from the x edge it is given to the first glyph of every typed thematic break (a storage run carrying `TokenStyle.rule`) and from its last glyph to the other edge, whole hyphens laid from the rule outwards, in the rule's font on its baseline, through Core Text: `EditorTextView.drawBackground(in:)` calls it with the view's bounds edges, since `NSTextView` clips `drawGlyphs(forGlyphRange:at:)` to the text container (which paints the extensions itself, container-wide, only when no text view draws the container); the extension is drawn, never inserted, so the text, selection, caret and copy never see it. Before the glyphs, `drawBands` fills every second section between rules (the rule's line first in its section; a rule on line one opens the first, unfilled section) with `quaternarySystemFill` between the x edges it is given, each band from its rule's hyphen midline (`hyphenMidline(of:)`, the centre of a hyphen's ink in the rule's font on its baseline) to the next rule's, clipped to the drawn lines (a rule line drawn alone gets the closing band's upper half): `EditorTextView.drawBackground(in:)` calls it with the view's bounds edges from the view's own unclipped background pass, since `NSTextView` clips the layout manager's `drawBackground(forGlyphRange:at:)` to the text container (which paints the bands itself, container-wide, only when no text view draws the container); the rule list is read once from the storage and kept current by `processEditing` for the edited lines only, redrawing the view when a rule comes or goes. `EditorLayoutManager.ruleRanges(in:)`, `allRules`, `sectionStarts`, `bandRanges(in:)`, `bandRects(in:in:)`, `hyphenMidline(of:)`, `ruleExtension(for:in:)`, `RuleExtension` (`rule`, `rect`, `baseline`, `leading`, `leadingBaseline`), `extensionColor`, `extensionCharacter`, `bandColor`, `drawRuleExtensions(forGlyphRange:at:fromX:toX:)`, `drawBands(forGlyphRange:at:fromX:toX:)`, `drawBackground(forGlyphRange:at:)`, `drawGlyphs(forGlyphRange:at:)`.
- `Sources/MDNotesApp/EditorStyler.swift` — syntax styling of headings, links, tags, code (code in the monospaced font, E-8); headings bold at 1.4 / 1.25 / 1.1 / 1.0 times the base size by level, `#` runs and setext underlines at that size, code in a heading at the heading's size, all following the Cmd-plus size (ED-4); list items' paragraphs hang at the marker's width plus two spaces' width per nesting level, measured in the base font, so wrapped lines align under the item text, bullet and ordered alike (ED-5); task boxes in the mono font and done items' content secondary (ED-6); ## Where things happen

- Search query path: keystroke, `MainWindowController.searchQueryDidChange`, `SearchIndex.query` (`Sources/MDNotesCore/SearchIndex.swift`), `NoteListController.show`.
- Enter in the search field: `MainWindowController.commitQuery`, `NoteCreation.noteID(forQuery:)`, `LibraryController.create`; rejections shown by `MainView.showMessage`.
- List rows and dates: `Sources/MDNotesApp/NoteListController.swift` + `NoteRowView.swift`; date strings in `RelativeDateText.swift`; snippets in `Core/BodySnippet.swift`.
- Editor styling: `Sources/MDNotesApp/EditorStyler.swift` (colours/weights/fonts) over tokens from `Sources/MDNotesCore/MarkdownScanner.swift`; scope in `restyleAfterEdit`. Drawing that is not text (ED-8's rule extensions, ED-10's section bands) is `Sources/MDNotesApp/EditorLayoutManager.swift`, reading the `.rule` runs the styler marked while it draws the visible glyphs.
- Autosave: `Sources/MDNotesApp/EditorController.swift` (`flush`) scheduled by `AutosaveClock.swift`, written by `Core/AtomicWriter.swift`, logged in `Core/OwnWrites.swift`.
- File watcher: `Sources/MDNotesCore/FSEventsWatcher.swift`, `OwnWrites.suppressing`, `LibraryController.apply`, `SearchIndex.applying(changes:store:)`. An image file that changes on its own travels as `LibraryChanges.images`: `SearchIndex.applying(imageChanges:images:)` re-resolves the notes embedding it, then `MainWindowController.libraryDidChangeExternally` hands the paths to `NoteListController.imagesDidChange` (rows) and `EditorThumbnails.imagesDidChange` (inline thumbnails). A template file's change travels as `LibraryChanges.templates` (by name, `TemplateStore.name(forRelativePath:)`): the index ignores it and `LibraryController.listTemplates` re-lists `templates/` into `templateNames` (TP-7).
- Templates: `Sources/MDNotesCore/TemplateStore.swift` lists `templates/` and reads one file (TP-1, TP-2); `Core/TemplateParser.swift` parses and expands it (TP-2, TP-3); `LibraryController.templateNames` is the live list (TP-7). Instantiation (TP-4): `MainWindowController.instantiateTemplate(named:title:in:)` asks `LibraryController.instantiate`, which reads the template on its queue, plans it with `Core/TemplateInstantiation.swift` (C-3 via `NoteCreation`) and writes through the same path as `create`; the window then opens the note and `EditorController.placeCaret(at:in:)` puts the caret at `{{cursor}}` once the load lands; a rejection's `localizedDescription` is the inline message. Template mode (TP-5): `Core/TemplateQuery.swift` reads the `@` query; `MainWindowController.showList` hands `NoteListController.show(templates:)` one `TemplateRow` per matching name in `LibraryController.templateNames`, the snippet expanded from `parsedTemplates`; Enter goes `commitQuery` to `commitTemplateQuery` (title check via `Template.pathNeedsTitle`) to `instantiateTemplate`; `onTemplateNamesChange` re-hands the rows.
- Links and tags: extraction in `Core/NoteReferences.swift`; maps in `Core/LinkIndex.swift` / `Core/TagIndex.swift`; opening in `MainWindowController.openLink` (a wikilink) and `openExternalLink` (a standard link's, autolink's or bare URL's destination through the injectable `openURL`, `NSWorkspace.open` by default), both reached from `openLink(at:)`/`openLinkAtCaret()` via `EditorController.link(at:)` (K-3); the Cmd-hover's link lookup is `EditorTextView.linkRange`, installed in `attach` over `EditorController.link(containingCharacterAt:)` (ED-12); rename rewrite in `Core/LinkRewrite.swift`.
- Completion popovers: `Sources/MDNotesApp/CompletionController.swift` with rules from `Core/LinkCompletion.swift` and `Core/TagCompletion.swift`.
- Global hotkey: `Sources/MDNotesApp/GlobalHotKey.swift` (Carbon), value in `HotKey.swift`, recorded by `HotKeyRecorder.swift`, wired in `AppDelegate.setHotKey`.
- Settings window: `Sources/MDNotesApp/PreferencesWindowController.swift`; backing defaults in `LibraryRootPreference.swift`, `EditorFontPreference.swift`, `HotKey.swift`.
- Menus: `Sources/MDNotesApp/MainMenu.swift`; item enablement via `MainWindowController.validateMenuItem`; app-level items in `AppDelegate.swift`. `File > New from Template` (TP-6): `AppDelegate` gives the submenu a `TemplateMenuDelegate` reading `libraryController.templateNames`, so it follows TP-7 and L-1 as it opens; a row's action is `MainWindowController.newFromTemplate(_:)`, which instantiates with no title or, when `Template.pathNeedsTitle`, puts `@name ` in the search field (template row selected, caret at the end) and asks for the title inline; Enter then goes the TP-5 way.
- Rich paste (ED-13): HTML on the pasteboard goes through `Core/HTMLToMarkdown.swift` (Foundation's `XMLDocument` tidy), RTF through `Sources/MDNotesApp/RTFToMarkdown.swift` (AppKit's RTF reader and `NSFont` traits); `EditorTextView.paste(_:)` picks the form (image, HTML, RTF, string) and inserts the result, `pasteAsPlainText(_:)` the string alone (ED-14, `MainMenu`'s `Paste and Match Style`, Cmd-Shift-V); the conversion runs on the main thread under PF-9 (`Tests/MDNotesAppTests/PastePerfTests.swift`).
- Images and embeds: `Sources/MDNotesApp/ImagePasteboard.swift` (decode off-main), `LibraryController.storeImage`, `Core/ImageStore.swift`; resolution via `LibraryController.locateEmbed`; each note's first existing image resolved at index time by `ImageStore.firstImage(in:)` into `SearchIndex.Entry.firstImagePath` (M8.2). Thumbnails: `ThumbnailCache.swift` (M8.1), owned by `NoteListController.thumbnails` and looked up under `imageRoot` (set by `MainWindowController.attach`) as rows are made, shown by `NoteRowView.showThumbnail` (M8.3). Editor attachments (E-9): `EditorText.swift` strips display-only runs and maps indices for every reader of the view's text (save in `EditorController.flush`, copy in `EditorTextView.writeSelection`, `EditorStyler`, `EditorController.linkTarget`/`tag`); `EditorController.addAttachment`/`removeAttachments` are the primitives (M8.4); `EditorThumbnails.swift` decides which embeds get one, looking targets up through `LibraryController.locateEmbed` and the shared cache and reconciling after every edit; a click on one goes `EditorTextView.onClick` to `MainWindowController.openThumbnail` (M8.5).
- iCloud download status: `Core/NoteStore.isDownloaded`/`isAvailable`, `Core/DownloadRequester.swift`, `LibraryController.EvictionStatus`, `EvictionBar.swift` / `ReadOnlyNoticeBar.swift`.
- Perf tests and budgets: budgets in `Sources/MDNotesTestSupport/PerfGate.swift`; fixtures in `SyntheticLibrary.swift`; gates in `Tests/MDNotesCoreTests/IndexPerfTests.swift`, `IndexMemoryPerfTests.swift`, `Tests/MDNotesAppTests/LaunchPerfTests.swift`, `ListPerfTests.swift`, `EditorPerfTests.swift`, `BacklinksPerfTests.swift`, `PastePerfTests.swift`.
